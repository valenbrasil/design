# Input

Campo de texto de uma linha com ícone à esquerda opcional (`iconLeft`) e estados visuais de foco (`--ring`), `invalid` (borda `--danger-500`) e `disabled`. `type` aceita qualquer tipo HTML de input (`"text"`, `"email"`, `"password"`…). Tamanhos `sm`/`md`(padrão)/`lg`. Use sempre dentro de um `Field`.

```jsx
<Input id="email" type="email" iconLeft="mail" placeholder="nome@valenbrasil.com" />
```
