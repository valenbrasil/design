# Select

`<select>` nativo estilizado, com seta `chevron-down` à direita. Cada opção pode ser uma string simples ou `{ value, label }`; `placeholder` vira a primeira `<option value="">` desabilitada visualmente por convenção. Tamanhos `sm`/`md`(padrão)/`lg`.

```jsx
<Select options={["Itajaí", "Balneário Camboriú"]} placeholder="Cidade" />
```
