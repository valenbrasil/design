# Avatar

Círculo com foto (`src`) ou iniciais do `name` (até 2 letras), usado em listas de usuários, comentários e cabeçalhos de perfil. Tamanhos: `sm` (28px), `md` (40px, padrão), `lg` (56px), `xl` (80px). Sem `src`, mostra as iniciais sobre fundo `sage-100`.

```jsx
<Avatar name="Marcela Duarte" size="md" />
```
