# Button

Botão de ação do sistema. Variantes: `primary` (padrão, fundo sage-500), `secondary`, `outline`, `ghost`, `link`, `destructive`. Tamanhos `sm`/`md`(padrão)/`lg`. `iconLeft`/`iconRight` recebem um nome de ícone Lucide (renderizado via o componente Icon). Com `href`, renderiza `<a>` em vez de `<button>`.

```jsx
<Button variant="primary" iconRight="arrow-right">Solicitar avaliação</Button>
```
