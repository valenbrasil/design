# IconButton

Botão quadrado apenas com ícone. `label` vira o `aria-label` — sempre obrigatório, mesmo sem texto visível. Variantes: `ghost` (padrão), `outline`, `solid` (fundo sage-500), `subtle`. Tamanhos `sm`/`md`(padrão)/`lg`.

```jsx
<IconButton icon="chevron-right" label="Próxima página" variant="outline" size="sm" />
```
