# Alert

Aviso inline com fundo tonal e ícone à esquerda — nunca borda colorida à esquerda. Tons: `info` (padrão), `success`, `warning`, `danger`, `brand`; cada tom já define um ícone padrão (sobrescrevível via `icon`).

```jsx
<Alert tone="danger" title="Não foi possível entrar">Verifique o e-mail informado e tente novamente.</Alert>
```
