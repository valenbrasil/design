# Tooltip

Dica contextual que aparece no hover/foco do elemento filho. `children` é o elemento que dispara a dica (normalmente um IconButton); `label` é o texto mostrado. `placement` controla se aparece acima (`"top"`, padrão) ou abaixo (`"bottom"`).

```jsx
<Tooltip label="Editar laudo"><IconButton icon="pencil" label="Editar" /></Tooltip>
```
