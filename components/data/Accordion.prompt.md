# Accordion

Lista de perguntas e respostas (FAQ) que expande um item por vez. `defaultOpen` é o índice aberto por padrão (`-1`, padrão, começa tudo fechado). O ícone `plus` gira 45° para virar "×" ao abrir.

```jsx
<Accordion items={[{ question: "Quanto tempo leva um laudo?", answer: "3 dias úteis para a avaliação mercadológica." }]} />
```
