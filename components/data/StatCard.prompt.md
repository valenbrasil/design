# StatCard

Cartão de métrica de painel: eyebrow (`label`) + ícone opcional, valor em destaque (tipografia display, `--type-h3`) e uma variação opcional (`delta`) colorida por `deltaTone` (`up` = verde, `down` = vermelho, `neutral` = cinza, padrão).

```jsx
<StatCard label="Laudos em aberto" value="24" delta="+3 esta semana" deltaTone="up" icon="trending-up" />
```
